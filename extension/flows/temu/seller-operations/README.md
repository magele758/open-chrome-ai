# Temu 商家数据与活动试填

在 PageLens 选择 Temu 数据工作流，插件会打开对应的商家页并读取。如果当前标签已经是对应页面，读取会沿用当前筛选。在侧栏点击「报名结果」等来源可以直接切换报表并读取。下载支持 JSON 和 CSV。

| 功能 | 支持页面 |
| --- | --- |
| 商品数据 | 商品列表，保留商品、经营站点、报价和 SKU 数据 |
| 活动数据 | 营销活动列表、报名结果、报名记录 |
| 营销数据 | Temu 商品推广页面上的数据表、可读取指标 |
| 订单数据 | 卖家履约订单列表，导出业务列，过滤收货信息列 |
| 资金数据 | 资金中心、对账中心、结算数据、资金限制。资金中心可读货款账户余额卡片和提现记录 |

可选择读取当前筛选的多页记录，每次最多 25 页。遇到无法确认的分页、页面切换或登录失效时，侧栏会提示并保留已读取的结果。页面确认暂无记录时，仍可下载来源、筛选和页面指标。

打开活动试填会读取当前报名表，或者打开营销活动页供你选择活动。选定活动后在侧栏重新读取报名表。勾选要试填的商品并核对申报价和库存后执行。回放会确认商品行和字段回读值。只有页面存在可验证的后续步骤时，侧栏才提供继续填写。流程停在最终提交前。

运行定向回归测试：

```sh
node scripts/run-tests.mjs temu/seller-operations
```
