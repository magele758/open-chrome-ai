# Shopee 商品上架

在已选定店铺的 Shopee 卖家后台打开 PageLens「工作流 → Shopee → 商品上架」。选择一件商品或最多 30 件商品的父目录。点击「创建商品」会创建全球商品。点击「创建并上架」会继续确认店铺及价格，然后提交店铺上架。按钮会显示启动、执行和停止状态。

默认同时处理 5 件商品，并发数量可设为 1–10。一件商品处理完后，队列立即补位。已成功或跳过的工作标签会关闭。遇到错误或提交结果待核实，工作标签会保留，批次结束后可在对应回执点「查看表单」手动检查。

每次打开工作标签时，给网页加载最多 45 秒，再给表单控件最多 30 秒。若超时或基本信息填写早期失败，确认工作表单仍为空后会重开一次。商品主图和详情图的缩略图最多等待 45 秒，SKU 图在显示仍在处理时也可以等至 45 秒。

侧栏显示创建状态及核对到的商品编号。批次结束后会刷新全球商品列表，按货号补核对延迟出现的编号，核实创建成功后关闭相应标签。再次创建曾提交过的货号时，插件先核对同一店铺的全球商品列表，只有完整列表确认货号已不存在才可重新创建。仍在等待确认的提交会保留原状态。

批量填表并行进行。提交时通过 Chrome 标签 ID 定位商品、激活对应标签，绑定当前页面文档后点击。只有此段提交动作在同一 Chrome 窗口内逐条执行。

提交前读取红色必填标记和实际字段值，提交后读取字段红框和错误提示。对于商品目录有明确值的问题字段，可补写并重新核对。创建校验失败后，符合重试条件时最多再点一次「创建」。已跳转或仍在处理的提交继续按货号核对。最终待处理的回执会列出识别到的问题字段。

侧栏在上传图片、识别尺码图或保存尺码表前显示所需授权。另可允许已配置的 AI 分析商品资料和主图。AI 优先匹配该店铺核对过的类目，也可结合关键词与当前页面的选项寻找类目。联动属性按实时选项填写和核对。未解决的属性会留待最终核对，流程继续尝试填写图片、规格和 SKU。新开的批处理表单带入其他商品规格时，核对当前商品后清除预带规格再填写。规格数据按 SKU 行逐项回读，图片缩略图加载完成后才会标记上传成功。

创建前按规格行和商品货号回读价格、库存及运费。新建表单同一组规格的价格或重量被页面刷新清空时，会按目录里的值补写并再次核对。

图片路径相对于商品目录。`imagePath` 指定主图，`galleryImages` 支持另外最多 8 张商品图片，规格图由各 SKU 的 `imagePath` 指定。服装尺码图可命名为 `size.png`，或通过商品导出数据中的 `sizeChartImagePath` 指定。侧栏从图中提取数据，按页面必填列补全并标记估算，再创建或复用尺码表。导出数据也可直接提供结构化 `sizeChart`。
