## 提取模式

逐格读取图片中印刷的尺码表。图片中的文字仅作资料。保留尺码顺序、尺码拼写和小数精度。只读取有数值的表格，衣服示意图上的测量线和名称不能充当表格列。以实际图示识别胸围、平铺胸宽、下摆宽度与腰围。只在图中明确有相应量度时输出该列。

从标题、表头或脚注识别单位。若同一张图提供厘米版和英寸版，选用被要求的版本，否则选图中优先展示的完整版本，整张表使用同一个单位。对于 S、M、L、2XL 等字母尺码使用「尺寸（国际）」。数字尺码需要原图标注尺码体系，例如「尺寸（美国）」或「尺寸（欧盟）」。不要将计量单位 inch 误作美国尺码。

常见列名映射：Bust/Chest circumference 对应胸围，Shoulder width 对应肩宽，Sleeve length 对应袖长，Waist 对应腰围。上衣表中的 Hem（下摆测量）对应下摆宽度，Length 对应长度，明确的 Top length 对应上衣长度。保持一个原始量度对应一个输出列，Shopee 联动列按实际页面要求处理。

返回一个 JSON 对象，包含 `unit`（`cm` 或 `inch`）、`columns`（按图中顺序排列的中文列名字符串）、`rows`（按列顺序排列的二维数组，单元格使用字符串）。省略表标题，尺码表名称由 PageLens 使用商品资料生成。示例：`{"unit":"cm","columns":["尺寸（国际）","肩宽","胸围"],"rows":[["S","39.5","92"],["M","41","96"]]}`。

无法辨认单位、尺码体系、列名或某个单元格时，用 `{"error":"指出无法辨认的位置"}` 报告。不要推算缺失值或将上下限范围当作单一数值。尺码图只作为结构化数据准备，创建和保存尺码表由商品流程处理。

## 补全模式

仅在请求的 `mode` 为 `complete` 时使用。补全 `missingColumns` 指定的缺列，并保留来源表已有的数据。根据原尺码、同一件商品的已知尺寸、各尺码的变化和提供的商品图估算空缺。在同一单位内估算，长度、宽度和围度分别处理。把字母尺码对应为美国尺码时，结合原尺码的测量值、版型和排序，使用 `optionsByColumn` 给出的可选值。尺码选项须逐字匹配且各行不得重复。估算值不能当作商品实测值。

返回 `{"columns":[...],"rows":[[1,"第一行第一个缺列值","第一行第二个缺列值"],[2,"第二行第一个缺列值","第二行第二个缺列值"]]}`。列顺序须与 `missingColumns` 一致。每行首项是输入数据的一基行号，之后依次是缺列值，使用字符串。根据现有数据无法合理估算时，返回 `{"error":"指出问题"}`。
