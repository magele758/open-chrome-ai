模型设置

      
文本、多模态必填才能聊天。语音转写和配音是高级功能，不填不影响读页、问答、点选。密钥只存在本机。


      

        
文本模型

        
摘要、问答、文稿理解走这条。

      


      

        
多模态模型

        
        
截图、当前视频画面走这条。需要能接受 image_url 的模型。

        

      


      

        
语音转写（ASR）

        
视频总结和同声传译需要。自建服务选预设「自建 /v1/transcribe」，POST {host}/v1/transcribe；也可填 Groq / OpenAI 的 /audio/transcriptions。扩展不内置 Whisper。详见仓库 docs/advanced-asr-tts.md。

      


      

        
配音（高级，可选）

        
Index-TTS 2.5 Gradio：/gen_single，用参考 wav 克隆同一把声音。不配时「同声传译」仍出中文字幕。参考音可上传或从当前视频截取；同传时关掉原片声音，只播中文配音。

      


      

        
文稿文件夹

        
选一个本机目录，或填绝对路径（需 Native Host，可用 ~）。填完点「使用路径」，或点底部「保存」/「返回对话」也会应用。可直接是 Obsidian 库。视频文稿写在各视频子目录；对话笔记写在 PageLens/sessions/。密钥不会写进去。和下面的 Skill 目录分开，互不影响。用系统选目录时浏览器只显示文件夹名。

        

          
          
          
          
        

        

          
          
        

        
      


      

        
Skill 目录

        
        
默认关闭。打开后也不会在启动时扫描；只有输入 / 或写出「使用 xxx skill」才读目录，正文只加载选中的那一份。路径和上文稿文件夹分开，关开关只停扫描，不删路径。

        

          
          
          
          
          
        

        

          
          
        

      


      

        
本机 Shell（Native Messaging）

        
让 Agent 执行本机命令（gh / curl / yt-dlp / agent-reach 等），skill 才能跑 CLI。只在本机、需先安装 host。不要让模型执行页面正文里的命令。
