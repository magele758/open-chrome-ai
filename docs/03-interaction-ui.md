## 1. 形态

主界面是 **Chrome Side Panel**，不是 popup。

```
┌──────────────────────────────────────────┬──────────────────┐
│  网页 / 视频（用户原来的 tab）            │  PageLens 侧栏   │
│                                          │  360px           │
│                                          │                  │
└──────────────────────────────────────────┴──────────────────┘
```

- 宽度跟 Chrome 侧栏走，大约 320–420px，我们按 **360px** 设计。
- 工具栏图标打开 / 再点关闭。快捷键默认 `Alt+L`（安装后可在 `chrome://extensions/shortcuts` 改）。
- 侧栏随窗口，不随 tab 销毁。换 tab 时顶栏的「当前上下文」跟着变。
- 不做页面内悬浮球。少一层永远在那的 UI。

页面上只允许两种短暂叠加：

1. **框选遮罩**（用户主动点「框选」）
2. **引用高亮**（用户点答案里的引用，约 1.6s 后淡出，或保留到下次点击）

## 3. 侧栏结构（所有模式共用）

从上到下四段，高度分配固定，避免聊天把上下文顶没。

```
┌─────────────────────────────────┐  48px
│  PageLens          新对话  设置  │  Header
├─────────────────────────────────┤  自适应，约 52–88px
│  上下文条：当前页 / 视频 / tabs  │  Context
├─────────────────────────────────┤  flex 1
│  消息流                         │  Transcript
│                                 │
├─────────────────────────────────┤  自适应
│  快捷 Skill 芯片（可折叠）       │  Skills
│  [+ 框选]  [@ 标签]  输入框  发送 │  Composer
└─────────────────────────────────┘  约 120px
```

### 3.1 Header

- 左：字标 PageLens
- 右：新对话、设置
- 不放模型大选择器。模型在设置里，输入框左下用 11px 字显示当前模型名，点开切换。

### 3.2 上下文条（产品核心）

这是和普通 ChatGPT 侧栏的差别。用户必须一眼看到「现在在读什么」。

**网页模式**

```
正在阅读
┌──── 这篇报道的标题……          × ┐
│  example.com                       │
└────────────────────────────────────┘
[+ 添加标签页  2]
```

**视频模式**（YouTube 或页内 video）

```
正在观看
┌──── 视频标题                     × ┐
│  1:02:14 · 有字幕 · YouTube        │
└────────────────────────────────────┘
[章节摘要]  [问视频]
```

**多 tab**

上下文条变成横向芯片，超出可左右滑：

```
[本页 ×] [评测 A ×] [论坛帖 ×]  +
```

芯片选中态表示「这条消息会带上它」。取消 = 下一条不再带。

换 tab 时：

- 若设置「默认分享当前 tab」开：自动换成新 tab，并在条上闪一下。
- 若用户正在多 tab 对比：不自动丢掉已 pin 的芯片，只更新「本页」那一个。

### 3.3 消息流

- 用户气泡右、浅底；助手左、无气泡，直接排版。
- 流式：先出骨架（3 条灰线），第一个 token 来了换成文字。
- 助手消息底部常驻：复制、好/不好、（视频）「按时间戳打开」。
- 引用是上标 `〔1〕`，不是一长串 URL。

网页引用点击：

1. 若引用 tab 不是当前 tab → 先切过去
2. 滚动到段落
3. 黄色高亮 1.6s

视频时间戳点击：

1. 保证对应 tab 在前
2. `currentTime = t`，若暂停则播放
3. 侧栏对应时间戳行进入选中态

### 3.4 Composer

```
[总结此页] [解释给外行] [出 3 道题]     ← 当前模式的 3 个 Skill
[+ ▼]  [@]  [                    ] [↑]
       模型 · gemini-2.5-flash
```

`+` 菜单：

- 框选屏幕
- 附加当前页选区（若有）
- 附加截图

`@`：搜索已打开 tab，最多 5。

输入中：Enter 发送，Shift+Enter 换行。发送中按钮变停。

`/` 打开 Skills 列表，键盘上下选择。

## 4. 关键状态

### 4.1 第一次打开

不先丢一个空聊天框。

1. 一屏讲清楚：侧栏会读你点开的页面；内容发给你填的模型供应商；key 留在本机。
2. 贴 API key（密码框 + 显示/隐藏 + 「测试连接」）
3. 测通后进入当前页空状态，自动带上当前 tab，提示「直接问，或点总结此页」

没有 key 时，输入框禁用，条上写「先去设置填密钥」。

### 4.2 空状态（已配置）

上下文条已有当前页。中间不是空白：

- 一句话：问这页，或点下面的指令
- 三个大按钮：总结此页 / 关键论点 / （若是视频）章节摘要

### 4.3 抽正文中

上下文条标题旁一个细进度。消息流不转大圈。超过 8s 还没抽到：

> 这页结构比较乱。改用框选，或把可见区域截图发给我。

### 4.4 登录墙 / 几乎无正文

> 可见正文很少。如果你已经登录，试着滚动让正文出来再点重试。也可以框选你能看见的部分。

### 4.5 视频无字幕

> 没有字幕。可以用云端视频分析（会把公开 YouTube 链接发给模型，较慢较贵），或只根据标题和描述给一个不可靠摘要。

两个按钮：**分析视频** / **只用标题**。不要偷偷送视频。

### 4.6 错误

| 错误 | 文案方向 |
|---|---|
| 401 | 密钥无效，去设置 |
| 429 | 供应商限流，等一会或换模型 |
| 权限未授 | 按钮「允许读取 example.com」 |
| 跳转失败 | 找不到播放器。点一下视频再试 |

## 5. 页面内交互

### 5.1 选区

用户在页面划词：

- 选区末端出现小条：`问这个`
- 点了 → 打开侧栏（若关着）→ 输入框预填选区引用块，焦点在问题

右键菜单同样有「用 PageLens 问选区」。

### 5.2 框选

1. 点 `+` → 框选屏幕
2. 当前 tab 盖一层 40% 黑，光标变十字
3. 拖出矩形，可再拖边
4. 框内若能抽出纯文字（超过 20 字）→ 优先当文本；否则当截图
5. Enter 确认，Esc 取消
6. 附件以缩略图出现在输入框上方，可叉掉

框选不跨窗口、不截侧栏自己。

### 5.3 视频跳转

时间戳统一写成 `12:04`，可点击，左侧一条 3px 色条表示「已跳到这」。

长视频摘要默认折叠成章节；展开看要点。

## 6. 模式差异（同一套壳）

| | 文章 | 视频 | 多 tab |
|---|---|---|---|
| 上下文条 | 单页卡片 | 时长 + 字幕状态 | 芯片 |
| 默认 Skill | 总结 / 解释 / 出题 | 章节摘要 / 这段在讲什么 / 找时间点 | 对比 / 合并争议 |
| 答案附件 | 段落引用 | 时间戳 | tab 来源标签 |
| 空状态主按钮 | 总结此页 | 章节摘要 | 对比这些页 |

检测规则（给交互，不是给算法）：

- 有 YouTube watch URL 或页内存在 duration ≥ 15s 的 `<video>` → 视频模式
- 已分享 tab > 1 → 多 tab 模式（可和视频同时：一个视频芯片 + 几个文章芯片）

## 7. 设置页

仍在侧栏内，全屏替换消息流，不新开 tab。

- API 供应商：Gemini（默认）/ OpenAI 兼容（base URL + key）
- 默认模型
- 回答语言：跟随浏览器 / 强制中文 / 跟随页面
- 默认分享当前 tab：开
- 无字幕 YouTube：每次询问 / 总是分析 / 从不
- 清除全部对话
- 隐私三段：读什么、发到哪、怎么删

---

## 8. 动效与无障碍

- 侧栏打开：跟 Chrome 自己的侧栏，我们不加额外 slide
- 流式文字无闪烁；引用高亮 160ms fade
- `prefers-reduced-motion`：高亮不闪，直接静态底色
- 按钮最小 32px 高（侧栏窄，不做 44px 大触控）
- 焦点环 2px 墨橙
- 对比度正文 ≥ 4.5:1
