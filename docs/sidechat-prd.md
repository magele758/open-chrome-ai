# PageLens — SideChat（旁注式裂变子会话）功能 PRD

- **版本**：v1.0
- **所属模块**：PageLens Side Panel (`extension/sidepanel/`) & 会话存储 (`extension/lib/sessions.js`)
- **核心隐喻**：**论文/书籍边缘批注 + 对话流局部裂变（Fork）**

---

## 1. 一句话定义

在主对话流的任意模型回复中，针对不理解的词汇、句子或段落**原地划词（或按消息节点）裂变出独立的旁注子会话（SideChat）**；所有裂变会话按所属主会话严格隔离，在右侧专属列表集中管理、持久保存，不打断主阅读流、不污染主线上下文，且日后回看历史会话时可顺着原文批注随时找回当时的扩展思考。

---

## 2. 背景与痛点

用户在使用 PageLens 读长文、看论文、学技术教程时，主对话流往往在推进一条「主线任务」（例如：总结整篇论文、推导核心架构）。阅读模型返回的长回复时，高频出现以下断点：

1. **主线污染**：只为了弄懂回复里的一个术语（如 `KV Cache`、`RoPE`）就在主输入框追问，导致刚刚生成的完整解答被顶出屏幕，且主线上下文塞满了枝节问答。
2. **新开会话割裂**：为了不打断主线而点「新对话」，新会话既丢失了当前网页和主线刚才的语境，又与原回答彻底脱钩，事后完全想不起当时是在哪句话卡住的。
3. **多点困惑难以并行**：一篇复杂回答里常同时有 2–4 个想展开的点，单线程线性对话无法像书本旁注一样「哪里不懂点哪里，各自独立展开、互不干扰」。
4. **学习记录无法沉淀**：传统划词翻译/即时气泡是「阅后即焚」的，无法围绕一个难点继续多轮追问，也不能在几天后回翻历史记录时看到「我当时对这句话是怎么想通的」。

---

## 3. 设计原则

1. **主线神圣（Non-disruptive Main Stream）**：SideChat 的创建、多轮追问、流式生成，**绝不插入**主对话消息流，也不改变主对话滚动位置。
2. **按会话隔离，锚点永续（Session-Isolated, Persistent Anchoring）**：每个主会话独占自己的 `sideChats` 列表，互不串台；只要主会话还存在，批注高亮与 SideChat 历史就跟着会话一起持久存在（IndexedDB）。
3. **语境继承，分支隔离（Forked Context, Isolated Growth）**：创建 SideChat 时自动拍摄主线截至该节点的上下文快照；之后子会话内部怎么展开，都不污染主线后续对话及其他 SideChat（除非用户主动点击「引用回主线」）。
4. **窄宽自适应（SidePanel First）**：Chrome 侧栏默认较窄（约 `380px–460px`），同时支持用户拉宽或独立窗口打开（`≥ 680px`）。右侧管理列表在这两种宽度下均保持可用与舒适阅读。
5. **1 + N 扁平裂变**：严格保持「1 条主对话 + N 条并列 SideChat」，SideChat 内部不再继续向下裂变二级 SideChat，防止认知迷航。

---

## 4. 功能详细设计

### 4.1 三种裂变触发入口
1. **划词浮动工具条（主力入口）**：在已完成输出的 `.msg.bot .body` 内选中任意文本（长度 `≥ 2`），弹出 `[💬 旁注追问 | ✨ 通俗解释 | 复制]` 浮动菜单。
2. **消息底部 `⑂ 裂变` 按钮（节点裂变）**：在 `.msg.bot .msg-actions` 新增 `⑂ 裂变`，针对整条回复快速开分支讨论。
3. **右侧管理面板 `+ 新建裂变`**：基于当前会话最新已完成回复直接新开分支。

### 4.2 宽窄自适应布局
- **宽屏分栏（容器宽度 `≥ 680px`）**：左侧为主对话流，右侧常驻 SideChat 管理与对话专栏。
- **窄屏抽屉（容器宽度 `< 680px`）**：主对话流保持全宽 + 右边缘锚点色标轨；点击高亮批注或顶部 `⑂ 旁注` 胶囊后，右侧滑出 SideChat 抽屉（支持列表页与详情页切换，按 `Esc` 或点击左侧微露遮罩一键收起）。

### 4.3 双向锚点定位与学习增强
- **正向跳转**：原文中被批注片段高亮显示并附带角标（区分 `💬 思考中` / `✓ 已掌握` / `📌 已凝练`），点击即定位右侧对应 SideChat。
- **反向定位**：在 SideChat 顶部锚点卡点击 `↗ 定位原文`，主对话平滑滚动到原句并播放 1.2s 脉冲高亮。
- **学习微技能**：提供 `💡 通俗类比`、`🧩 举个例子`、`🔍 深挖原理` 以及 `📌 凝练一句话批注`（提炼结果直接悬停可预览、列表可展示、并写入 Obsidian）。
- **引用回主线**：SideChat 内任意回答支持 `↩ 引用到主线`，将精华结论带入主输入框待发送区，不强行污染主线历史。

### 4.4 知识沉淀与跨会话回顾
- **Obsidian / Markdown 导出**：在主会话对应回复下生成 `> [!note] 旁注 · ...` Callout 块，保留原句、凝练批注与多轮思考。
- **知识盘点聚合视图**：在「知识盘点（`#view-review`）」新增 `💬 旁注笔记` 标签页，支持跨全部历史会话按状态/关键词检索批注，点击即可打开原会话并直达该批注分支。
