## 1. 一句话

在当前网页旁边打开一个侧栏，问「这一页 / 这段视频在讲什么」，答案带引用，视频答案带时间戳，点一下跳回去。

不离开页面，不先复制粘贴，不先开一个新的 AI 标签。

---

## 2. 为什么做

Gemini in Chrome 已经把这个品类做成立方体了：侧栏、当前 tab、最多 10 个 tab、YouTube 摘要 + 时间戳跳转、框选提问、Skills。

但它有三道门：

1. **进不去**：地区、语言、登录、企业策略、Incognito。中国用户基本等于没有。
2. **出不去**：模型和数据绑在 Google 账号上，页面内容进 Gemini Apps Activity。
3. **视频浅**：官方深耕 YouTube；课程站、B 站、本地 HTML5、内嵌播放器几乎不管。

本产品做「能用的 Gemini in Chrome 内容理解」，主场是：

- 网页读懂
- 视频读懂（YouTube **和** 通用视频）
- 用户自己的模型密钥
- 中文优先

---

## 3. 谁用

主用户：用 Chrome 做研究 / 学习 / 决策的人，每天开一堆 tab，看长文和长视频。

三张脸（都服务，不拆产品）：

| 角色 | 场景 | 成功长什么样 |
|---|---|---|
| 学习者 | 看 40 分钟教程，只想找「怎么配环境」那 3 分钟 | 问一句，跳到 12:04 |
| 研究者 | 5 篇论文/报道对着看 | 侧栏出对比表，每格能点回源页 |
| 决策者 | 商品页 + 评测视频 + 论坛帖 | 「这三页的核心争议是什么」 |

非用户：要 AI 自动下单、自动填表、接管浏览器的人。那是 auto browse，本版本不做。

---

## 4. 产品原则

1. **上下文默认在，但可见。** 打开侧栏就带上当前 tab；顶上永远能看到「正在读哪些页 / 哪段视频」，一键取消。
2. **先理解，后行动。** MVP 只读、只答、只跳转。不替用户点按钮。
3. **答案必须能点回去。** 网页有段落引用，视频有时间戳。没有引用的总结算失败。
4. **视频是一等公民，不是 YouTube 彩蛋。** 任何带 `<video>` 的页都应该能问。
5. **用户按一次才工作。** 不后台常驻读页面。
6. **密钥在用户这边。** 默认 BYOK；不强制注册我们的账号。

---

## 5. 目标 / 非目标

### 目标（MVP 必须成立）

- 任意普通网页：摘要、问答、解释，延迟可接受（见指标）
- YouTube：摘要、章节、问答、点击跳转
- 用户能看到并控制「当前在分享什么」
- 中文 UI + 中文回答（页是外文时，按用户语言答）
- 用用户自己的 API key 跑起来（Gemini API 为默认供应商）

### 明确非目标（v1 不做）

- Auto browse / 代填表 / 代购物 / 代登录
- 接入 Gmail、Calendar、Drive、Maps
- Gemini Live 语音对谈
- 用 Nano Banana 生成信息图（理解 ≠ 生成）
- 浏览器历史「回忆你上周看过什么」
- Firefox / Safari
- 把官方 Gemini 图标皮套过来（商标和审核风险）
- 无字幕且无法抽帧的 DRM 视频硬解

## 6. 功能范围

优先级：

- **P0**：没有就不能叫这个产品
- **P1**：第一版后立刻做，体验会从「能用」变成「愿意每天开」
- **P2**：对标官方完整助手，或强差异化，但不挡发布

### P0 — 读懂当前页

| ID | 功能 | 用户可感知行为 | 验收 |
|---|---|---|---|
| F1 | 侧栏主界面 | 点工具栏图标或快捷键，右侧打开面板，页面仍可滚动 | 面板在当前窗口打开；刷新页面面板还在 |
| F2 | 默认带上当前 tab | 打开即显示标题 + favicon +「正在阅读」 | 顶栏能取消分享；取消后模型不再用该页 |
| F3 | 页面摘要 | 一键「总结此页」，流式输出 | 正文页 3 秒内出第一个 token；广告/导航不进摘要 |
| F4 | 针对页面问答 | 自由输入，基于页面回答 | 回答里有可点击引用，点击滚动并高亮源段落 |
| F5 | 选区提问 | 页内选中文字 → 右键或悬浮「问这个」 | prompt 里带选区，不带整页噪声 |
| F6 | 框选提问 | 类似 Select from Screen：画框，文字或截图进对话 | 框选图片也能问「这是什么」 |
| F7 | 新对话 / 历史 | 新开聊天；最近会话可找回 | 按 URL 可续聊；清历史有按钮 |
| F8 | 设置 | API key、默认模型、语言、是否默认分享当前 tab | key 只存在本地 `chrome.storage.local`，不打日志 |

### P0 — 读懂视频

| ID | 功能 | 用户可感知行为 | 验收 |
|---|---|---|---|
| V1 | 视频页识别 | YouTube 或页内有 `<video>` 时，侧栏切到「视频」上下文 | 显示时长、标题、是否有字幕 |
| V2 | 视频摘要 | 一键摘要：主题 + 要点 + 时间戳列表 | YouTube 有字幕时，2 分钟内出带时间戳的摘要 |
| V3 | 视频问答 | 「他什么时候讲了 X」 | 答案含 `mm:ss`，点击后播放器跳转且误差 ≤ 2s |
| V4 | 章节列表 | 自动章节，点击跳转 | 无官方章节时仍能生成 |
| V5 | 字幕降级说明 | 无字幕时明确告诉用户将走抽帧/ASR，可能更慢更贵 | 不假装已经看懂 |

YouTube 是 P0 的必过站点。通用 HTML5 视频：能识别、能跳转、能在有字幕轨时问答，即算 P0 过关；无字幕的通用视频允许走 P1 的抽帧路径。

### P0 — 跨 tab

| ID | 功能 | 验收 |
|---|---|---|
| T1 | @ 或选择器添加最多 5 个打开的 tab（MVP 先 5，官方是 10） | 顶栏显示全部已分享 tab |
| T2 | 「对比这些页」 | 输出表格或优缺点，每条能回到对应 tab |

### P1 — 让人每天开

| ID | 功能 | 说明 |
|---|---|---|
| S1 | Skills / 斜杠指令 | `/总结` `/对比` `/出题` `/视频章节`；可自定义 |
| S2 | 页面内引用高亮 | 回答引用点击后，源页高亮 + 可选在页内插入笔记条 |
| S3 | 无字幕视频 | 抽关键帧 + ASR（或云端视频 API） |
| S4 | 多模态页 | 把页内关键图一起送进模型（产品页、课件） |
| S5 | 本地 Nano 回退 | 若 Chrome Prompt API 可用，短摘要走本地，不耗 key |
| S6 | 导出 | 复制 Markdown；带引用和时间戳 |
| S7 | 站点适配 | PDF 查看器、Google Docs 可见文本、Notion、微信公众号 |

### P2 — 以后再说

- 更多 tab（10）
- Live 语音
- 生成式配图
- 弱 agent（只读规划，不自动点）
- B 站 / 课程平台深度适配
- 团队空间 / 自有后端账号

## 7. 核心用户流程

### 流程 A — 读一篇长文

1. 用户打开文章，点 PageLens。
2. 侧栏出现，顶栏显示当前标题。
3. 用户点「总结此页」或直接问「这篇文章的结论是什么」。
4. 流式回答，每条要点后面有引用标记。
5. 用户点引用，页面滚动到对应段落并短暂高亮。

失败时：抽不到正文（登录墙、应用页）→ 明确说「这页几乎没有可读正文」，提供「改用截图提问」。

### 流程 B — 看一条 YouTube

1. 打开 youtube.com/watch。
2. 侧栏识别为视频，展示时长和字幕状态。
3. 用户点「章节摘要」或问「环境配置在哪一段」。
4. 返回带时间戳的列表。
5. 点击 `12:04`，视频跳转并播放。

失败时：无字幕且用户拒绝云端视频分析 → 只提供「根据标题/描述的弱摘要」，并标注不可靠。

### 流程 C — 对比三个商品 tab

1. 用户开 3 个商品页，在侧栏用 @ 加上另外两个。
2. 点 Skill「对比」。
3. 得到规格表。点某一格切到对应 tab。

### 流程 D — 框选图提问

1. 用户点 `+` → 框选。
2. 画出页面上的图或一段文字。
3. 附件出现在输入框。
4. 问「这个错误信息怎么处理」。

## 8. 上下文模型（产品规则，不是实现细节）

一次提问的上下文包，用户必须能看见：

```
ContextPack {
  tabs: [{ tabId, url, title, mode: "full-page" | "selection" | "screenshot" }]
  video?: { tabId, currentTime, duration, captionStatus, title }
  selection?: { text | imageBlob, rect }
  userPrompt: string
  skillId?: string
  language: "zh-CN" | ...
}
```

规则：

- 默认只带 **当前 tab**。
- 视频页同时带页面元数据 + 字幕/视频信号，不把整页评论区当正文。
- 有选区时，选区优先，整页当可选背景（UI 上是一个开关：「同时参考整页」默认开）。
- 用户取消某个 tab 后，下一条消息立刻不再包含它。
- 不默认读取未打开的浏览历史。

## 9. 内容类型与质量条

| 页面类型 | P0 必须可用 | 质量条 |
|---|---|---|
| 文章 / 博客 / 文档 | 是 | 摘要覆盖主论点和限制条件，不编造未出现的数字 |
| 商品页 | 是 | 能列出价格、规格、卖点；价格以页上为准 |
| YouTube | 是 | 时间戳可跳；不把评论当视频内容 |
| 普通 HTML5 视频 | 部分 | 有字幕轨则问答可用 |
| SPA 应用后台 | 尽力 | 抽不到就截图路径，不崩溃 |
| PDF（Chrome 自带查看器） | P1 | — |
| 需要登录才有正文 | 是（用户已登录的 tab） | 只读用户已经能看见的 DOM，不绕过付费墙去爬站 |

幻觉政策：涉及价格、日期、步骤、时间戳，必须绑定引用。绑不上就说「页上没找到」。

## 10. 权限与信任（产品层）

用户必须在 UI 上理解这三件事：

1. **此刻读了哪些 tab**（芯片列表）
2. **会不会把内容发给模型供应商**（状态条：本地 Nano / 云端 Gemini / 未配置）
3. **API key 存在哪**（设置页一句话：仅本机，扩展卸载即无）

权限申请原则：

- 安装时不要一上来 `<all_urls>` 吓人。优先：侧栏 + scripting + 当前站点可选权限。
- 第一次在某站点点「总结」时再请求该 host。
- YouTube 可以预声明，因为是 P0 站点。

## 11. 成功指标

定性：用户不复制粘贴、不换标签，就能完成「弄懂这一页/这条视频」。

定量（内测，无后端也能在本地记）：

| 指标 | MVP 目标 |
|---|---|
| 文章摘要首次 token | < 3s（网络正常、key 有效） |
| 有字幕 YouTube 摘要完成 | < 30s |
| 时间戳点击跳转成功率 | ≥ 95%，误差 ≤ 2s |
| 引用点击能落到源段落 | ≥ 80%（动态页允许失败并提示） |
| 从打开侧栏到发出第一条有效问题 | < 15s（含第一次填 key） |
| 无 key / 无权限 / 抽正文失败 | 必须有明确下一步，不许转圈死 |

## 12. 风险

| 风险 | 级别 | 处理 |
|---|---|---|
| Chrome Web Store 对「读所有网页 + 调 AI」审核严 | 高 | 可选权限、清晰隐私政策、不传 key 到自有服务器 |
| YouTube ToS / 字幕接口变更 | 高 | 字幕解析隔离成适配器；失败走官方公开 API 或用户可见的页面字幕 DOM |
| 把整页 DOM 送进模型导致隐私事故 | 高 | 默认抽正文；密码框、input[type=password]、隐藏节点剔除 |
| 模型在时间戳上幻觉 | 中 | 时间戳必须能在字幕或抽帧索引里对上，对不上就标「约」 |
| 和官方 Gemini 视觉太像被拒 | 中 | 独立品牌、独立图标，文案不出现「官方 Gemini」 |
| DRM / MSE 流无法抓帧 | 中 | 降级为字幕或截当前画面（canvas 可能是黑的，要检测） |
